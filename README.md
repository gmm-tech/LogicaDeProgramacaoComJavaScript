Repositório dedicado ao domínio da lógica de programação e fundamentos de algoritmos utilizando JavaScript. Desenvolvo soluções estruturadas passo a passo, abordando estruturas de controle e conceitos fundamentais de programação.

---

### 🛠️ Conceitos Abordados

* **Operações Básicas e Entrada/Saída:** Manipulação de variáveis, operadores aritméticos, leitura e exibição de dados.
* **Cálculos e Fórmulas:** Porcentagem, médias, conversão de unidades e equações matemáticas aplicadas.
* **Estruturas Condicionais Simples e Compostas:** Tomada de decisão utilizando `if`, `else if` e `else`.
* **Estruturas Condicionais Aninhadas:** Encadeamento de condições para resolução de problemas com múltiplas regras.
* **Operadores Relacionais:** Comparação de valores (`>`, `<`, `>=`, `<=`, `===`, `!==`).
* **Operadores Lógicos:** Construção de expressões utilizando `&&`, `||` e `!`.
* **Estruturas de Repetição:** Utilização de `while`, `do...while` e `for` para execução repetitiva de instruções.
* **Análise de Algoritmos e Teste de Mesa:** Rastreamento manual de variáveis e validação da lógica dos programas.

---

### 🚀 Como Executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/gmm-tech/LogicaDeProgramacaoComJavaScript.git
   ```

2. Abra os arquivos HTML no navegador.

3. Execute os exercícios através da interface disponível no projeto.
