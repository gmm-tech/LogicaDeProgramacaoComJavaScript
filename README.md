Repositório dedicado ao estudo e à prática de lógica de programação e fundamentos de algoritmos utilizando JavaScript. Aqui, os mesmos exercícios desenvolvidos anteriormente em VisualG são reimplementados em JavaScript, aplicando os conceitos fundamentais da programação em uma linguagem amplamente utilizada no desenvolvimento de software.

---

### 🛠️ Conceitos Abordados

* **Operações Básicas e Entrada/Saída:** Manipulação de variáveis, operadores aritméticos e interação com dados utilizando `prompt()` e `alert()`.
* **Cálculos e Fórmulas:** Porcentagem, médias ponderadas, conversão de unidades e equações matemáticas aplicadas.
* **Estruturas Condicionais Simples e Compostas:** Tomada de decisão utilizando `if`, `else if` e `else`.
* **Estruturas Condicionais Aninhadas:** Encadeamento de condições para resolução de problemas com múltiplas regras de negócio.
* **Operadores Relacionais:** Comparação de valores utilizando `>`, `<`, `>=`, `<=`, `==`, `===`, `!=` e `!==`.
* **Operadores Lógicos:** Construção de expressões complexas utilizando `&&`, `||` e `!`.
* **Variáveis e Tipos de Dados:** Utilização de `let`, `const`, números, strings e valores booleanos.
* **Conversão de Dados:** Conversão de valores recebidos como texto utilizando `parseInt()` e `parseFloat()`.
* **Análise de Algoritmos e Teste de Mesa:** Rastreamento manual de variáveis e validação da lógica dos programas.

---

### 🚀 Como Executar

Os exercícios podem ser executados diretamente no navegador utilizando o Console do JavaScript.

1. Clone este repositório:

```bash
git clone https://github.com/gmm-tech/LogicaDeProgramacaoComJavaScript.git
```

2. Acesse o diretório:

```bash
cd LogicaDeProgramacaoComJavaScript
```

3. Abra os arquivos `.js` no navegador ou em seu editor de código.

4. Para executar os exercícios que utilizam `prompt()` e `alert()`, abra o **Console do navegador** e execute o código.
